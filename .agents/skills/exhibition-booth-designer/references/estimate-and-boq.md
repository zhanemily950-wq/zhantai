# 工厂核价、材料BOM与预算沟通

## 必须拆分

1. 制作：木结构/金属结构/标准展具/展墙、地台、玻璃亚克力、五金、饰面与画面。
2. 标识与视觉：LOGO、背光字、灯箱、软膜/喷绘、画面安装。
3. 展示设施：陈列柜、锁柜、展示台、屏幕与多媒体设备（区分租赁/购买）。
4. 灯具电气：照明、线路、电箱、专业安装、官方供电费用。
5. 搭建拆除：工人人数、加班、现场运输搬运、设备机具。
6. 物流与管理：打包、往返运输、仓储、现场管理、维护保洁。
7. 展馆相关：报馆、审图、押金、清运、场地或指定管理费用（明确代缴/可退）。
8. 税费、风险预留、项目变更：分别说明口径，不与材料价混算。

每个条目字段：序号、区域、构件、材料规格、工艺、单位、数量、损耗、单价（原始报价来源）、金额、供应商、报价有效期、是否含运输安装、状态、备注。

## 核价原则

- 未从工厂取得单价时写“待核价”，不要以历史均价伪装正式报价。
- 预算上限不等于可行报价；如预算不足，按“保留 / 替换 / 删除”的优先级列出可见效果与成本影响。
- 一项修改同时更新效果图描述、材料表、施工条件、费用与工期，留有版本和原因。
- 同时比较“首次搭建成本”与“重复利用成本”，注明仓储、物流和损耗。
- 不用“含所有费用”代替明细，明确押金可退、报馆费用和临时加项是否计入合同。

## 关键防追加问题

核实以下是否在原报价范围：额外柜体、亚克力盒、补强方案、电源/网络/水、额外画面修改、超时搭建、叉车与吊装、展馆收费、撤展清运、客户自带设备接线、特殊运输、防火资料、现场修改。

## 客户沟通（客观版）

“这版方案的主要成本集中在{具体构件}。为了保证视觉效果和落地，我们建议保留{关键展示点}，把{非核心异形/材料}改成{可替代做法}。价格需要根据最终材料规格和工厂核价确认，报馆与展馆代收项目会单独列明，尽量避免后期额外增加。”

生成报价清单可直接从 `assets/报价清单模板.csv` 开始，不得填入无来源的单价。
