# 交付文件与版本规范

## 设计阶段建议目录

```
项目目录/
  project.json                  # 输入参数/版本/确认状态
  01-客户需求.md
  02-方案方向对比.md
  03-平面分区与动线.md
  04-效果图提示词.md
  05-材料BOM与预算.csv
  06-落地风险与待确认.md
  07-修改记录.md
  references/                  # 客户提供的手册、LOGO、参考图
  renders/                     # 已实际生成的渲染文件
  drawings/                    # 已实际生成的CAD/PDF等图纸
```

## 版本

统一编号 `V01-日期`、`V02-日期`。每个版本写明：客户输入变化、保留项、修改项、对费用/工期/报馆的影响、待客户确认项。文件未生成就不要在交付文案里列为已交付。

## 交付质量门槛

- 平面说明与效果图提示词中尺寸、开口、品牌、柜体数量一致。
- 重要构件材料与成本表对应，不存在效果图展示但报价漏项。
- 明确“待工厂核价/待展馆审批/待结构或电气复核”。
- 客户自有展品数量、产品尺寸和保留区块未被无声修改。
- 输出中每个费用、规范、展馆说法均可追溯来源；未知不猜。

## 最少客户版呈现

“已确认需求 → 概念优势 → 分区说明 → 3张关键视角（如实际有图）/出图提示词 → 主要材料 → 费用范围与核价状态 → 风险清单 → 待确认事项”。
