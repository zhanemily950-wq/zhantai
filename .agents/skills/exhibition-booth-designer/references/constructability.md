# 展台设计施工落地审查清单

## 证据层级

1. 展会/展馆当期官方参展与搭建手册、管理要求、书面批复。
2. 经确认的客户需求、展位平面与产品资料。
3. 有资质人员签发的施工图、结构及电气设计、计算书（按项目要求）。
4. 工厂正式报价、节点样板、供货证明和搭建排期。
5. AI创意图与过往经验——仅供参考，不能替代以上确认。

所有结论必须写明“已证实/需确认/风险”。未见手册就不要写“该展馆允许4.5米”“可以吊装”等未经验证的判断。

## 审图维度

| 维度 | 审查事项 | 风险控制 |
| --- | --- | --- |
| 几何与展位边界 | 实测长宽、柱子、消防设备、开口、临展侧退让 | 以正式图纸与展馆要求为准 |
| 结构 | 展墙、门头、桁架、独立站立构件、悬挑、抗倾覆、连接与配重 | 需要专业工程复核，禁止仅凭渲染图推断安全 |
| 吊挂 | 吊点、吊重、主办许可、资质操作 | 没批准就用非吊挂替代概念 |
| 设备与承重 | 大型设备重心、地面荷载、电梯与叉车运输 | 核实设备真实重量、占地与展馆承载 |
| 防火 | 材料燃烧性能、消防器材可达、疏散及封闭空间限制 | 按当届官方规范与法规核验 |
| 电气照明 | 负荷、线路、配电、漏电保护、供电办理、灯具散热 | 专业电工/专业设计确认 |
| 材质工艺 | 板材、涂装、玻璃/亚克力、边角、防刮耐磨 | 工厂打样、出节点详图 |
| 运输安装 | 分件尺度、包装、进馆门洞、车辆、工期、工人数量 | 制定生产与搭建进度表 |
| 报馆费用 | 审图、用电、场地、清运、押金、超时/加班 | 按主办方报价与合同条款列示 |
| 后期维护 | 展品补货、柜门开启、储物通风、清洁与撤展 | 检查操作空间和通道 |

## 风险分级

- **阻断级**：明显可能导致倾倒、坠落、触电、阻断疏散、违反明确审批条件；暂停工程定案，交专业人员与展馆复核。
- **重要级**：成本、交期、工艺、展品信息严重不清；先做替代方案或补资料。
- **普通级**：视觉平衡、展品分组、灯光层次、品牌可读性问题；进入设计优化。

若发现高风险，先提出不涉及详细危险施工方法的安全替代思路（如降低独立门头复杂度、使用可经审核的支撑体系、减少非必要悬挑）并要求资质审核。不可输出未经校核的结构规格、配重值或现场临时加固操作指令。

## 报告格式

`问题编号 / 图纸位置 / 问题描述 / 证据状态 / 风险级别 / 对效果的影响 / 建议方向 / 责任人或待确认方`。

结尾必须说明“本报告为概念与落地协同审查，不替代工程审图和展馆审批”。
