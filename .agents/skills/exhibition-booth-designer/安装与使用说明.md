# Codex 展台设计 Skill｜Windows 完整安装与使用说明

> 2026-11-03 更新。Codex 官方当前说明的个人 Skill 目录为 `$HOME/.agents/skills`，**不是**旧版的 `~/.codex/skills`。
> 官方文档：https://developers.openai.com/codex/skills（现跳转至 https://learn.chatgpt.com/docs/build-skills ）

## 一、使用前确认

- 电脑：Windows 10 或 11。
- 已安装、登录 ChatGPT 桌面应用中的 Codex，或 Codex CLI / IDE 扩展。尚未安装时参见：https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan
- 本 Skill 无需单独购买插件，也不要求安装 Python 才能使用设计分析、方案策划或提示词生成功能。Python 仅供可选的项目创建与资料完整性检查脚本使用。

## 二、手动安装（最推荐）

1. 下载 `Codex_展台设计_Skill_安装包.zip`。
2. 在 Windows 下载文件夹中右键 ZIP，选择「全部解压缩」。得到名为 `exhibition-booth-designer` 的完整文件夹。
3. 按 `Win + E` 打开资源管理器，点击地址栏，粘贴 `%USERPROFILE%\.agents\skills` 并回车。
4. 如果目录不存在：先进入 `%USERPROFILE%`，新建 `.agents` 文件夹，再在 `.agents` 内新建 `skills` 文件夹。
5. 把第 2 步的**完整** `exhibition-booth-designer` 文件夹复制到 `skills` 中（不是只复制 `SKILL.md`）。
6. 确认存在 `%USERPROFILE%\.agents\skills\exhibition-booth-designer\SKILL.md`。
7. 返回 Codex，新建对话；如未显示 Skill，完全退出 Codex 再启动。

**正确目录：**

```text
C:\Users\<你的Windows用户名>\.agents\skills\
└── exhibition-booth-designer\
    ├── SKILL.md
    ├── assets\
    ├── references\
    ├── scripts\
    ├── tests\
    └── 安装与使用说明.md
```

**常见错误：** 别形成 `...\skills\exhibition-booth-designer\exhibition-booth-designer\SKILL.md` 这样的双层目录。

## 三、验证是否安装成功

在 Codex 新对话输入：

```text
$exhibition-booth-designer
请先确认已经读取展台设计 Skill。然后列出你会执行的设计步骤，不要开始出图。
```

如果支持技能选择器，也可以在输入框里输入 `$` 找到 `exhibition-booth-designer`。Codex CLI 或 IDE 扩展可尝试 `/skills` 查看技能。注意：不同 Codex 客户端的按钮可能不同。

## 四、首次运行示例

```text
$exhibition-booth-designer
请设计一个 36 平方米、双开口的宠物食品展台。要求：现代简约、绿色与米白配色、产品陈列、客户接待、储藏区。先给出三种设计方向和分区思路，再给五个视角的 AI 效果图提示词，并列出工厂核价项及待核实的展馆规定。没有数据不要自行假设为已确认。
```

也可以上传现有展台效果图或平面草图后发送：

```text
$exhibition-booth-designer
根据我上传的展台设计图，分别从参展商体验、动线、材料预算、工厂可做性与搭建安全风险进行审查，提出可执行的修改建议。
```

## 五、可选：自动建项目文件

该 Skill 的脚本只是可选工具。如果电脑有 Python 3，可在 Skill 所在目录打开 PowerShell：

```powershell
py -3 scripts/init_project.py --name "宠物食品-上海展-36平米" --output ./projects
py -3 scripts/validate_brief.py "./projects/宠物食品-上海展-36平米/project.json"
```

如果提示 `py` 不存在，先检查 Python 是否已安装；也可把 `py -3` 换成 `python`。不运行脚本也不影响主要设计技能。

## 六、如果未识别

1. 确认安装在 **Windows 当前登录用户** 的 `%USERPROFILE%\.agents\skills` 下，而不是 `.codex\skills`。
2. 确认 `SKILL.md` 是文件、拼写大小写正确、位置正确，且开头有 `name` 和 `description`。
3. 重新开启 Codex 新会话，不行则完全退出重启。
4. 在 Codex CLI/IDE 扩展中尝试输入 `/skills` 或 `$exhibition-booth-designer`。
5. 如果你用的是 **WSL 内运行的 Codex CLI**，应放到 WSL Linux 用户的 `~/.agents/skills/`，与 Windows `%USERPROFILE%` **不是同一个目录**。
6. 如果仍无法识别，请提供 Codex 版本/使用方式、Skill 文件完整路径、错误截图以便定位。

## 七、能力边界

安装 Skill 不等于安装图片生成器、SketchUp 或 CAD。它能规范需求、概念方案、材料与预算拆解、工程风险检查和 AI 出图提示词；真正自动生成效果图或施工图需要额外配置相应工具，并对尺寸、安全、展馆规定做人工/专业核验。
