# 效果图提示词模板

**项目信息**：{品牌} / {展会} / {展馆} / {宽}m×{深}m / {开口方向} / {预算定位}

**基础几何约束**：保留展位边界、相邻展位位置、可进入的通道边；高度仅以客户提供且已证实的展馆限高为准。

**主提示词**：
专业商业展会定制展台，{品牌行业}，展台定位为{品牌风格}，品牌色{色系}，净尺寸{尺寸}，开口{开口}，品牌主视觉设置在{位置}。清晰的产品展示区{具体产品及数量}、洽谈区{人数}、仓储/后台{需求}，通道方向开放。主要材料{材质}，灯光{灯光}，品牌识别强、真实可制作的空间逻辑、结构比例可信、PBR材质、真实展馆环境、建筑摄影45度视角，高质量视觉呈现。

**强约束/负向提示词**：
不得改变{已确认几何和展品位置}。不得额外增加展位面积、超出官方限高、凭空生成可读Logo、无审批空中吊挂或悬挑结构、阻挡主通道、虚构不明承重结构。各视角位置数量保持一致。

**镜头变化**：主通道45度 / 正立面 / 次通道45度 / 俯视分区 / 材质特写。

**修改指令**：保留{不变部分}；只改变{变动部分}；不得改变{受控项目}；本次变更对预算与工期的影响{待核价/待确定}。
